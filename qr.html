Make a code for a trash can

Each code holds the can's coordinates, so scanning it shows the bins nearest to that can without asking for location.

    Stand next to the can

    Use your phone's location, or paste coordinates from Google Maps (press and hold on the spot, then copy the numbers).

    Check the site address

    Where this site is hosted. It fills in from the page you're on.

  3. 03

    Print the label

    Download the PNG and print it at least 2 in (5 cm) wide so phones read it from arm's length.
